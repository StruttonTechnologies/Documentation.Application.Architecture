# Chapter 4 — Microservices

In the previous chapter, the architecture was applied within a single application using modules.

The next step is understanding how the same architectural principles apply when systems are distributed across multiple services.

Microservices are often presented as a solution to architectural problems. In reality, they introduce a different set of tradeoffs.

This chapter explains how microservices relate to the architecture and what changes when systems become distributed.

## In this chapter, you will learn

- what microservices are  
- how the architecture applies across service boundaries  
- what benefits microservices provide  
- what additional complexity they introduce  

This chapter focuses on structure and tradeoffs, not implementation or infrastructure.
