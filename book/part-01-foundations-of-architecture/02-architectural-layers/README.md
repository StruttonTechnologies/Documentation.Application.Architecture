# Chapter 2 — Architectural Layers

In the previous chapter, software architecture was defined as the structure of a system.

The next step is understanding how that structure is organized.

Architecture is not a single concept. It is composed of architectural elements that work together to organize responsibilities, define boundaries, and manage complexity. One of the most fundamental of those elements is the architectural layer.

This chapter introduces layers as a conceptual model for organizing software systems.

## In this chapter, you will learn

- what architectural layers are
- how layers organize responsibilities
- how layers differ from physical structures such as projects or folders
- why layers help preserve clarity as systems grow
- common misconceptions and failure patterns involving layers

This chapter does not define the layers used by the Strutton Technologies Application Architecture.

Instead, it establishes the foundational concepts needed to understand why layers exist and how they should be used before they are applied throughout the remainder of this book.
