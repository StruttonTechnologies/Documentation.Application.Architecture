# Application DTOs

This section introduces **Application-level DTOs** as an Architectural Unit.

Application DTOs are shared data contracts used to transfer information without 
exposing internal models or execution behavior. They exist to support
communication between assemblies and layers in a controlled and enforceable way.

---

## Purpose of This Section

The purpose of this section is to explain:

- what Application DTOs represent in this architecture
- why they exist as a distinct Architectural Unit
- where they are used and where they are not
- how they differ from domain models and UI models
- the rules that govern their use
