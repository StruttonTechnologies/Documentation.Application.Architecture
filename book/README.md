# Application Architecture

## A Practical Guide to Boundaries, Layers, and Architectural Thinking

**Author:** Shawn Strutton  
**Organization / Imprint:** Strutton Technologies

**Edition:** First Edition  
**Format:** Markdown Working Draft

---

This repository is structured so the reader can move through the book in order using page navigation links. The root `README.md` serves as the cover and entry point for the book. Each page includes navigation at the bottom so the reader can move backward, return to the table of contents, or continue forward.

This volume is intentionally focused on architecture. It explains what the architecture is, why it exists, and how its parts relate at a high level. It does not attempt to teach implementation details. A separate volume will cover engineering and implementation.
