# Part 3 — Architectural Application Styles

In the previous parts, architecture was defined and then applied to a concrete system.

The next step is understanding how that same architecture can be used in different types of applications.

Architecture is often confused with deployment style.

Monoliths, service-based systems, and microservices are frequently treated as entirely different approaches. In practice, they are different ways of organizing and deploying the same underlying architectural principles.

This part explores those differences.

## In this part, you will learn

- how architecture applies at different system scales  
- how clean monoliths, service-based systems, and microservices differ  
- what changes between these approaches and what remains the same  
- how to choose the appropriate style for a given system  

This part focuses on structure and tradeoffs, not implementation.
